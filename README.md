# ecommerce

This repository now contains a working static storefront website for GitHub Pages.

## Included files
- `index.html` — landing page and store layout
- `styles.css` — styling for the storefront
- `script.js` — simple cart interaction

## Preview locally
Open `index.html` in a browser, or serve the folder with a local web server.

## Deploy to GitHub Pages
Push this repository to GitHub and enable GitHub Pages in the repository settings. The site will work as a static site from the root directory.
